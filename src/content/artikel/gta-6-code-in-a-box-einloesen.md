> **Stand: 19. November 2026.**

**Kurz gesagt:** Die Verpackung von GTA 6 enthält **keine Disc**, sondern einen **Download-Code**. Du löst ihn im PlayStation Store oder im Microsoft Store ein und lädst das Spiel dann herunter. Plane genug Zeit und Speicher ein: Das Spiel braucht bis zu 212 GB.

## Warum keine Disc?

Rockstar hat schon bei der Ankündigung der Editionen bestätigt, dass die „physische“ Version nur einen Code enthält. Das hat Folgen:

- Du brauchst zum Installieren **Internet**.
- Die Konsole ohne Laufwerk (PS5 Digital) reicht völlig.
- **Weiterverkaufen geht praktisch nicht**, weil der Code nach dem Einlösen an dein Konto gebunden ist.

## Code auf der PS5 einlösen

1. **PlayStation Store** auf der PS5 öffnen.
2. Oben rechts auf die **drei Punkte** (Mehr) gehen.
3. **Code einlösen** wählen.
4. Den **12-stelligen Code** eingeben und bestätigen.
5. In der Spielebibliothek GTA 6 auswählen und **herunterladen**.

Alternativ kannst du den Code im Browser auf der Website des PlayStation Store unter deinem Profil einlösen. Der Download startet dann automatisch, wenn die PS5 im Ruhemodus mit dem Internet verbunden ist.

## Code auf der Xbox Series X|S einlösen

1. **Microsoft Store** auf der Xbox öffnen.
2. Die **Ansicht-Taste** (zwei kleine Fenster) drücken und **Einlösen** wählen.
3. Den **25-stelligen Code** (fünf Blöcke) eingeben.
4. GTA 6 aus **Meine Spiele & Apps** installieren.

Am PC oder Handy geht es auch über **xbox.com/redeem**. Manchmal fragt Microsoft nach einer Zahlungsmethode. Dir wird dabei nichts berechnet.

## Der Code funktioniert nicht: Was tun?

Geh diese Punkte der Reihe nach durch:

- **Richtige Konsole?** Ein PS5-Code funktioniert nicht auf der Xbox und umgekehrt. Steht auf der Verpackung.
- **Richtige Region (PS5)?** PS5-Codes sind an die Region deines PSN-Kontos gebunden. Ein Code aus einem anderen Land funktioniert auf einem deutschen Konto oft nicht. Xbox-Codes sind laut Rockstar nicht regional gesperrt.
- **Tippfehler?** Ähnliche Zeichen wie 0 und O oder 1 und I verwechselt man leicht.
- **Schon eingelöst?** Jeder Code geht nur einmal. Wenn du ihn schon eingelöst hast, findest du das Spiel in deiner Bibliothek.
- **Spiel fehlt trotzdem?** Konsole neu starten, ab- und wieder anmelden und prüfen, ob du mit dem Konto angemeldet bist, auf dem du den Code eingelöst hast. Auf der PS5 hilft oft **Lizenzen wiederherstellen** (Einstellungen > Benutzer und Konten > Sonstiges).
- **Xbox-Konto gesperrt oder im Minus?** Dann lässt Microsoft keine Codes einlösen.

Hilft das alles nicht, wende dich an den **Händler, bei dem du die Box gekauft hast**. Rockstar verweist bei Käufen außerhalb des eigenen Stores an den Händler. Bewahre den Kassenbon und die Karte mit dem Code auf.

## Vorbesteller-Bonus und GTA+

Wer die Box vorbestellt hat, bekommt über denselben Code auch das **Vintage Vice City Pack**. Die Inhalte schalten sich im Spiel nach und nach mit der Story frei. Den Gratismonat **GTA+**, den es bei Vorbestellungen im PlayStation Store gab, gibt es laut Berichten bei der Box-Version nicht.
